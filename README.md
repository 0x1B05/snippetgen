# SnippetGen Demo

ELF-first PoC workspace for a XiangShan-focused snippet generator.

## Current Scope

This repository is being built in small RLCR rounds.

The first milestone is intentionally narrow:

- load a suite description
- load snippet manifests
- generate a harness
- produce `ELF` and `bin` artifacts

The current round only establishes the repository skeleton needed for that path.
